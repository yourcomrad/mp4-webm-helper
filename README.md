# MP4/WEBM Helper

MP4/WEBM Helper — enhanced userscript for direct video files (.mp4, .webm)

• 🔊 Volume control: Shift + mouse wheel, 1% step, remembers between videos and page reloads

• 🔁 Loop (repeat): remembers setting, toggle via right-click → Loop

• 💾 Quick save: Alt + click on video → instantly downloads without "Save As" dialog

• Works for direct videos opened in a new tab

• Note: Not compatible with YouTube, HLS/DASH streams, or protected video players
